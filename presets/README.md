# Portable toolbar preset

`development-layout.json` is the toolbar layout saved on 2026-11-27 for resuming
development on another computer. It is intentionally versioned at the user's
request and contains only portable toolbar configuration, with schema version 3.

Restore it using [Development setup](../docs/DEVELOPMENT_SETUP.md). This folder
does not contain Blender preferences, a startup workspace, or scene geometry.
The preset is separate from the install ZIP so installing an update does not
replace a user's existing toolbar layout.
